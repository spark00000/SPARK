## 4. No-extension Rule

`read_file`, `list_directory`와 같은 application tool 이름과 schema는 표준 MCP tool mechanism 안에서 정의할 수 있습니다.

SPARK는 다음을 요구하지 않습니다.

- custom MCP method
- custom protocol header
- proprietary framing
- hidden/non-standard session semantics

`/health`와 PID file은 local daemon 운영 기능이며 MCP protocol의 일부가 아닙니다.
